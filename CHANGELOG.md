# Changelog

## 0.2.2

- Fixed shop robot discounts doing nothing to Cart Compressor boxes.
- Removed the override that blocked the game's ItemAttributes.ValueDiscount method.
- The $15,000 floor now applies to regular shop pricing; a successful robot discount can reduce that price using vanilla rules.

## 0.2.1

- First public beta of the standalone Cart Compressor upgrade.
- Three personal levels: 76.67%, 70.83% and 65% cargo size.
- Vanilla cereal-box geometry with custom Cart Crunch artwork.
- Removed the development F9 item spawner and unused debug setting.
- Requires REPOLib; no ShrinkCart, ScalerCore or REPOConfig dependency.

## 0.2.0

- Local standalone prototype with a new scaling and synchronization implementation.

## 0.1.x

- Local development prototypes; not published.
