# Changelog

## 0.2.1

- First public beta of the standalone Cart Compressor upgrade.
- Three personal levels: 76.67%, 70.83% and 65% cargo size.
- Vanilla cereal-box geometry with custom Cart Crunch artwork.
- Removed the development F9 item spawner and unused debug setting.
- Requires REPOLib; no ShrinkCart, ScalerCore or REPOConfig dependency.
